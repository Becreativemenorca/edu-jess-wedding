ESTRUCTURA
- index.html = selector de las 3 plantillas
- mediterranean/index.html = toda Mediterranean en UNA sola página
- editorial/index.html = toda Editorial en UNA sola página
- modern/index.html = toda Modern en UNA sola página
- images/ = TODAS las fotos compartidas por las 3 plantillas

PARA VER LA WEB
1. Abre esta carpeta completa en Visual Studio Code.
2. Abre el index.html que está en la raíz.
3. Pulsa “Go Live”.
4. Se abrirá el selector con Mediterranean / Editorial / Modern.

PARA CAMBIAR LAS FOTOS
Todas están en la carpeta images/.
Si sustituyes una foto manteniendo exactamente el mismo nombre, se actualiza en las 3 plantillas.

PARA CAMBIAR NOMBRES / FECHA / LUGAR / TEXTOS
Busca “Clara & Marc” en el index.html de cada plantilla.
El código está formateado hacia abajo, con cada sección separada:
01 INICIO
02 NUESTRA HISTORIA
03 LA BODA
04 DESTINO
05 INFORMACIÓN
06 CONFIRMA
