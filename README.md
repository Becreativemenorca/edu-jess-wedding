# BeCreative Wedding Sites

Sistema reutilizable para gestionar webs de boda dentro del WordPress actual de Be Creative Weddings.

## Objetivo

Una sola instalación de WordPress, un solo plugin y varias bodas.

Cada boda almacena sus propios datos y selecciona una plantilla visual reutilizable.

## Primera fase

1. Registrar el contenido **Bodas** en WordPress.
2. Crear la ficha editable de cada pareja.
3. Convertir **Luxury Editorial** en la plantilla **Minimal Editorial** dinámica.
4. Dividir la experiencia final en páginas independientes:
   - Inicio
   - Nuestra historia
   - La boda
   - Nuestra Menorca
   - Información
   - RSVP
5. Usar **Edu & Jess** como primer caso real.

## Datos previstos por boda

### General
- Nombre persona 1
- Nombre persona 2
- Fecha
- Lugar
- Plantilla
- Imagen de portada
- Frase principal

### Historia
Bloques repetibles:
- Año / fecha
- Título
- Texto
- Fotografías
- Tratamiento visual destacado

### La boda
Bloques repetibles:
- Momento
- Espacio
- Hora opcional
- Texto
- Imagen

### Nuestra Menorca
Bloques repetibles:
- Categoría
- Lugar
- Texto personal
- Imagen
- Enlace opcional

### Información
Bloques activables:
- Cómo llegar
- Vuelos / ferry
- Alojamiento
- Transporte
- Coche de alquiler
- Parking
- Niños
- Calzado / dress code
- Otros

### RSVP
Se desarrollará después de validar la primera plantilla y el flujo de edición.

## Principios técnicos

- No duplicar instalaciones de WordPress.
- No duplicar una página Elementor completa por pareja.
- No modificar las páginas corporativas actuales.
- No depender de plugins adicionales salvo que aporten una ventaja clara.
- Optimizar imágenes antes de alojarlas.
- Mantener el código de plantillas versionado en GitHub.
- Probar antes de instalar o actualizar en producción.
